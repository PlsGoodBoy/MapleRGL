MapleRGL · 枫林幸存者 / 0.2.0

启动
解压整个文件夹后，双击 MapleRGL.exe。
请保留旁边的 assets 文件夹和三个 DLL，不能只复制 exe。
EXE、窗口和任务栏使用统一的像素枫叶图标。
运行环境：Windows 10/11 64位，支持 Direct3D 11，系统有微软雅黑或黑体。

基本操作
WASD或方向键：移动；空格：冲刺；E：互动；Esc：暂停或关闭详情。
攻击自动释放。升级时最多五选二，可按Esc全部跳过，也可选一项后按Esc跳过剩余。
打开详情或替换预览时，Esc先关闭详情或取消预览；战斗中Esc暂停/继续。
每级有一次免费重置，只更换未选卡；技能卡的“详情”用于查看完整效果。
八个主动技能槽，基础技能与融合技能共用。左栏显示真实等级、压制和主要搭配。
二十种基础共鸣不消耗技能；其中六种可通过升级选择互斥方向强化。
自动融合：所有当前材料真实等级各达到Lv.5即自动融合，释放槽位，不额外占升级选择。
共用材料优先四源、三源、二源，再按配方优先级和稳定ID处理；首次融合随机确定形态，本局重做沿用。
暂停后分页查看技能、共鸣、融合配方与强化，替换技能前会显示共鸣得失。
经典单局安排三次阶段首领和一次最终首领；60种怪物外观、24种Boss进入随机池。
70个基础技能、89种二源、12种三源、8种四源融合，合法续接见暂停融合页。
40种局内装备拾取即生效、持有数量无上限；暂停可看数量、当前贡献和下一件收益。
经典标准1×约20分钟、紧凑2×约10分钟有效战斗；选卡与暂停不计时。

技能表现
章鱼炮台使用原生枪手章鱼的本体、开火、墨弹和退场动画；召唤物分开部署，敌方弹道按来源区分。
烟幕呈现流动的灰蓝烟雾；扭曲力场显示通透钟面与缓慢指针，仅在实际范围内减慢敌我弹道。
自然秩序、退化和元素领域使用不同的纹理表达；高阶融合按实际路径、节点和命中组织。
机械工兵、导弹装置与幻影卡片部分采用原游戏同主题素材，尚非对应现代技能的完整还原。
自动融合显示材料icon汇聚和结果高亮，二/三/四源以不同边框区分。
设置中的友方特效不透明度和轻量特效可调节画面密度。
首领三项专属招式按生命阶段组合，危险预警保持正常战斗速度；击毁机制节点可削减后续攻击或打开破绽。
设置可调闪光强度、界面缩放并重看短引导；图鉴显示已遭遇首领和实际观察到的招式。

音乐
14类限流技能音色与八首原创Game Boy风格音乐，随战斗阶段平滑切换；暂停不会从头播放。
设置可分别调节音乐、战斗音效、界面提示音，并提供曲目试听。

存档
游戏自动使用当前用户的 %LOCALAPPDATA%\MapleRGL。
更新游戏文件不会覆盖该目录中的存档。
经典模式不恢复关闭时的战场；连续远征在章节完成时保存构筑。
资源或保存失败的详细记录位于存档目录的 logs 子目录，设置页可查看当前版本和资源路径。

版本与资源说明
本包更新时间及 exe 校验值见 VERSION.txt。
第三方程序库说明见 THIRD_PARTY_NOTICES.txt；素材来源说明位于 assets 中。
