# 音乐与音效

音乐引擎位于 `src/chiptune.hpp`，输出22050Hz单声道样本，由现有持续WaveOut混音播放。没有引入采样包、外部MIDI或新的音频设备框架；八首曲目均为项目编写的独立旋律、和声走向和节奏编排。

每首拥有独立A、B旋律与桥段，不是同一首曲子的调速或移调副本。普通战斗曲采用八小节分段的“稀疏引子→A→B→A变奏→桥段→回归”；高速Boss曲额外保留B变奏。两个营地主题采用A/B/桥段/回归。循环点为样本0至 `MusicTrack::loop_samples()`，持续循环时保留振荡器相位与包络。

音色由带边缘平滑的脉冲旋律、应答声部、三角波低音及噪声／低频打击组成。压力提高时沿同一拍点加强预写的打击与应答层，不随机拼接旋律。A变奏、桥段和回归有固定安排。

## 场景调度

App根据真实游戏状态选择场景，战斗时优先级为Boss存活＞主要高压阶段＞普通战斗。菜单、营地、胜利、失败为独立请求状态。引擎的请求可以每个音频缓冲重复提交；同一场景不会重抽曲目或重置歌曲。

- 同场景池有多首时避开上次实际使用的曲目；菜单和营地共用两首曲池。
- 音乐随机与游戏随机完全分离。
- 普通战斗／高压之间至少驻留24秒，高压请求持续4秒才换曲；从高压或Boss返回战斗还要求退出状态持续6秒。
- 轻度压力波动只改变当前乐曲的预定编曲层。主要阶段在小节边界切换，次要阶段在两小节乐句边界切换。
- Boss进入和营地／战斗转换不等待24秒；胜负结果立即开始平滑过渡。
- 不同曲目使用1.4秒线性交叉淡化，分别保持各自速度。没有强行对齐不同BPM的音符。
- 升级和暂停只平滑降低音乐增益，不重置样本位置。音乐接口没有遭遇节奏倍速参数。

短句包括升级、选择完成、秘卷获得、融合完成、Boss登场、胜利、失败，共七种。它们走单独的 `cue` 通道，优先级较高的短句可以通过12毫秒交叉淡化替换低优先级短句，低优先级提示不排成长队；融合、Boss及胜负短句短暂降低BGM。普通命中音不触发音乐闪避音量。

## App接口

```cpp
music.request_scene(scene, pressureIntensity); // 先由App按真实Boss/压力状态确定优先级
music.set_softened(pausedOrChoosing);
music.cue(MusicCue::Fusion);                   // 只在对应行为实际完成时调用
auto sample = music.next_sample();            // { music, cue }
// music与cue分别乘音乐、UI提示音音量，再与已有战斗音效相加
```

`tracks()` 返回稳定ID、中文标题、场景、BPM、小节、循环样本数和秒数。`track_index()`、`playhead_seconds()`、`scene()`、`transition_count()` 可用于试听页或简洁诊断。

`audition(index)` 使用相同引擎试听指定曲目。试听期间场景请求仅暂存，退出 `end_audition()` 后淡化回真实请求场景。导出工具使用 `audition(index, false)`，避免把旧曲的淡出混入纯曲目文件。App使用独立通道接口。

## 技能音效

`src/skill_sfx.hpp` 为钢刃、暗影、毒、枪火、机械、拳劲、龙、冰、雷、火、圣光、奥术、卡牌和玫瑰提供14类合成音色。声部最多12个，施放、命中和收尾分别限流，高阶融合加入短和声。

[技能音色示例](audio/skill-sfx.wav)每段先播放基础施放和命中，再播放高阶施放、命中和收尾。

`export_music` 可导出8首完整循环及场景过渡样本；`preview_skill_sfx` 可导出技能音色样本。音频由22050Hz单声道脉冲、三角与噪声合成，未提取原作音频。
