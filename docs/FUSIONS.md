## 2源结果与允许入口

### 回旋贯星 (`star_return`)

贯穿后回旋，回程在有限目标间跳转。

- 穿透箭 Lv.5 + 弹射箭 Lv.5 → Lv.3
### 霜雷领域 (`frost_storm`)

寒霜领域周期传导雷电，对寒霜目标追加受限碎冰。

- 冰咆哮 Lv.5 + 连锁闪电 Lv.5 → Lv.3
### 龙魂战甲 (`dragon_armor`)

攻击或护盾吸收积累龙魂；满100层自动咆哮并获得护盾。受到伤害降低10%。

- 龙咆哮 Lv.5 + 防御反击 Lv.5 → Lv.3
### 焚天箭雨 (`phoenix_rain`)

凤凰标记区域，箭雨集中落下后留下燃烧地带。

- 凤凰 Lv.5 + 箭雨 Lv.5 → Lv.3
### 追猎箭阵 (`hunter_volley`)

标记强敌后分批追踪齐射，目标死亡时剩余箭矢重新选敌。

- 精准射击 Lv.5 + 多重箭 Lv.5 → Lv.3
### 熔星灾变 (`molten_star`)

火域积累热量，最多引发两次延迟陨落和地面爆发。

- 火焰领域 Lv.5 + 陨石 Lv.5 → Lv.3
### 奥术星环 (`arcane_ring`)

魔弹在星环中积蓄，再分批脱离轨道追踪敌人。

- 追踪魔弹 Lv.5 + 魔法阵 Lv.5 → Lv.3
### 万剑回旋 (`sword_cyclone`)

跟随自身的剑环周期发射外扩剑气。

- 旋风剑刃 Lv.5 + 剑气 Lv.5 → Lv.3
### 破阵连斩 (`dash_breaker`)

由玩家冲刺触发，沿实际冲刺轨迹追加斩击并在终点重斩；不会强制移动。

- 冲锋斩 Lv.5 + 劈空斩 Lv.5 → Lv.3
### 烈焰剑舞 (`flame_dance`)

旋转火刃沿移动路线留下数量受限的短暂火径。

- 旋风剑刃 Lv.5 + 火焰领域 Lv.5 → Lv.3
### 剑羽风暴 (`feather_storm`)

剑刃命中积蓄剑羽，按节拍向外散射。

- 旋风剑刃 Lv.5 + 多重箭 Lv.5 → Lv.3
### 星轨魔弓 (`star_bow`)

固定法阵节点使魔箭绕轨转向后追击，并进行有限弹射。

- 魔法阵 Lv.5 + 弹射箭 Lv.5 → Lv.3
### 斗气狂刃 (`battle_blades`)

连续斩击积累斗气，达到阈值后转入三次重斩。

- 劈空斩 Lv.5 + 斗气聚合 Lv.5 → Lv.3
### 龙魂贯阵 (`dragon_formation`)

锁定直线贯穿，随后在枪尖处爆发龙吼。

- 龙咆哮 Lv.5 + 枪连击 Lv.5 → Lv.3
### 回响圣盾 (`echo_shield`)

飞盾拦截弹丸积能，返身时将能量释放为震荡波。

- 防御反击 Lv.5 + 圣盾回旋 Lv.5 → Lv.3
### 破阵山河 (`mountain_breaker`)

仅由玩家实际冲刺触发，沿途留下延迟地裂，终点震地。

- 冲锋斩 Lv.5 + 地裂重击 Lv.5 → Lv.3
### 斗气圣裁 (`spirit_judgement`)

斗气化为连续审判印记，满层后集中裁决强敌。

- 圣剑审判 Lv.5 + 斗气聚合 Lv.5 → Lv.3
### 苍龙裂空 (`azure_rift`)

苍龙剑气贯穿后回返，沿命中位置留下有限裂空爆发。

- 龙魂突刺 Lv.5 + 剑气 Lv.5 → Lv.3
### 圣域裁决 (`sanctuary`)

飞盾落点形成短暂圣域，周期锁定域内敌人降下审判。

- 圣盾回旋 Lv.5 + 圣剑审判 Lv.5 → Lv.3
### 瘴炎连爆 (`poison_flare`)

毒雾积累后依次点燃三个分区，有限连爆后重新积毒。

- 毒雾 Lv.5 + 火焰领域 Lv.5 → Lv.3
### 雷霆冰枪 (`thunder_lance`)

冰枪布置有限节点，雷电沿节点间的真实路径传导。

- 冰枪 Lv.5 + 连锁闪电 Lv.5 → Lv.3
### 天国龙辉 (`heaven_dragon`)

圣龙吐息留下光辉走廊，光脉冲沿走廊继续攻击。

- 圣光 Lv.5 + 圣龙召唤 Lv.5 → Lv.3
### 炎魔陨阵 (`inferno_array`)

火魔兽标记猎物，连续三颗陨星围绕锁定目标落下。

- 火魔兽 Lv.5 + 陨石 Lv.5 → Lv.3
### 蚀骨旋涡 (`venom_vortex`)

牵引过程中积毒，结束时按最多三层毒进行有限爆破。

- 魔力漩涡 Lv.5 + 毒雾 Lv.5 → Lv.3
### 霜火双界 (`frost_fire`)

相邻寒霜与火焰区域交替，实际跨过边界触发受限冲击。

- 冰咆哮 Lv.5 + 火魔兽 Lv.5 → Lv.3
### 净化星井 (`purity_well`)

固定星井聚敌后周期圣光脉冲，恢复效果独立限流。

- 魔力漩涡 Lv.5 + 圣光 Lv.5 → Lv.3
### 千矢风暴 (`thousand_arrows`)

- 暴风连射 Lv.5 + 多重箭 Lv.5 → Lv.3
### 鹰眼绝杀 (`eagle_execution`)

银鹰先标记弱点，再用两次重型射击集中打击。

- 狙击 Lv.5 + 银鹰 Lv.5 → Lv.3
### 冰封箭幕 (`frozen_barrage`)

- 寒冰箭 Lv.5 + 箭雨 Lv.5 → Lv.3
### 破城轰矢 (`siege_bolt`)

贯穿路径留下最多四个爆破标记，按次序引爆。

- 爆炸箭 Lv.5 + 穿透箭 Lv.5 → Lv.3
### 诡雷草人 (`trick_decoy`)

- 诱敌草人 Lv.5 + 爆炸箭 Lv.5 → Lv.3
### 双翼巡猎 (`twin_hunt`)

- 凤凰 Lv.5 + 银鹰 Lv.5 → Lv.3
### 折光狙杀 (`prism_shot`)

- 狙击 Lv.5 + 弹射箭 Lv.5 → Lv.3
### 雷霆剑狱 (`thunder_prison`)

- 剑气 Lv.5 + 连锁闪电 Lv.5 → Lv.3
### 霜甲反击 (`frost_armor`)

- 防御反击 Lv.5 + 冰咆哮 Lv.5 → Lv.3
