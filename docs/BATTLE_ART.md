# 战场素材与动画

战场继续通过 Dear ImGui / Direct3D 11 绘制原始透明纹理。召唤、投射物和区域主体读取现有 `assets/manifest.json`；辅助范围、刻度、血条和敌方识别标记使用程序绘制。

## 召唤与发射

| 内容 | 来源与接入 |
| --- | --- |
| 章鱼炮台、深海舰队 | 枪手技能 `Skill.nx/521.img/skill/5211001/summon`，使用 stand、attack1、summoned、die；墨弹来自 attack1/info/ball，命中来自技能 hit/0 |
| 凤凰 | `Skill.nx/312.img/skill/3121006/summon`，原始飞行与攻击动画 |
| 银鹰、圣龙 | 原有 `3111005`、`2321003` 召唤动画，按真实攻击事件切换，参与实体排序 |
| 火魔兽 | `2121005` 伊弗利特；修正此前误用 `2221005` 冰系召唤本体的问题 |
| 暗影蝙蝠 | `Mob.nx/2300100.img/fly` 的原始蝙蝠本体，作为同主题追踪弹体；不是技能图标 |
| 机械工兵 | `Mob.nx/5110302.img` 的原始机械怪物本体和攻击动作，明确作为同主题友军替代 |
| 导弹装置 | `Mob.nx/9300004.img` 机械本体，配合 `5110302.img/attack1/info/ball` 实体导弹；同主题组合替代 |
| 幻影卡牌 | `UI.nx/UIWindow.img/Minigame/MemoryGame/card/back0` 原始翻牌卡背；是卡片纹理，非技能 icon，尚非幻影原技能弹道 |

章鱼统一按原像素的 0.9 倍绘制，不按各动作的边界重新缩放。炮口使用原始 `range/sp = [-23, -18]`，随本体比例和左右镜像转换。真实发弹时选择原动画 480 ms 的释放段；下一发可以中断恢复段，保持现有攻击频率。动画本身不生成弹药或伤害。

凤凰和银鹰也使用原始 `range/sp = [-24, -37]`，分别随 0.75 / 0.65 的本体比例转换。快速攻击选择释放段，短暂部署和退场使用源动画片段与淡入淡出，不为了播完整段长动画增加技能前摇或延长伤害存续。

地面召唤有分开的部署位置。召唤的待机、攻击计时和退场使用战斗时钟。烟幕、封印和有效等级归零时保留受限待机，不继续演出开火；融合消耗或替换会移除旧攻击实例，仅留下短暂的无伤害退场。

本轮直接相关的逻辑修正只有召唤部署/炮口对齐，以及受压制时不再递减多拍技能的固定拍间隔，防止解除压制后节奏异常。伤害倍率、冷却、召唤寿命、融合等级和配方未调整。

## 敌方弹道与命中

来源表覆盖当前 84 种敌人/Boss 外观。逐一检查原始攻击节点、`info/ball`、`info/hit` 和动作帧；其中 11 种外观存在原生独立弹体，直接使用对应资源，其余登记同主题候选。外观表包含近战单位，并不表示所有外观都会发动远程攻击。

雪人雪球、月光精灵魔弹、浮士德原始香蕉弹、地狱猎犬火弹等保留原始颜色与动画。敌方弹体额外使用暗边和小型方向标记，与友方区分，并在友方爆发之后绘制。追踪、扇形、旋转弹幕仍由原战斗逻辑决定；光束和地面攻击的纹理沿真实有限范围排列。

尾迹记录实际移动过的位置。扭曲力场中的 50% 弹速仍由原来的路径积分计算，多个力场不重复叠减。表现不额外改变速度或判定。

敌方弹体结束时区分实际伤害、护盾吸收、无敌、墙体碰撞和到期。无敌与吸收不会播放正常伤害爆炸；命中效果和消散仅作表现，不进入伤害逻辑。敌人折光抵挡沿用已有状态反馈。

## 区域

| 区域 | 表现 |
| --- | --- |
| 烟幕 | 原生 `4221006/tile` 烟雾，灰蓝配色；不同大小、不同动画相位的烟团缓慢漂移。低特效保留 7 层，普通保留 11 层，范围边界和玩家状态一直可见 |
| 扭曲力场 | `5121010` 时间跳跃原生钟表纹理，低透明银蓝刻度、长短指针和少量残影；在地面实体层下面绘制 |
| 自然秩序 | 原始圣印纹理与森林叶片的组合，低饱和绿金配色，表示装备贡献被压制 |
| 退化光环 | 原始封印符文，灰紫配色，符文向内收束；左栏仍显示真实等级和暂时失效的等级块 |
| 火焰、毒雾、寒霜、圣光与地裂 | 复用原生持续纹理与对应命中帧，沿实际圆形、线段或扇形组织；保留必要的判定边界 |
| 延迟爆炸 | 预告边界与生效爆炸分开，爆炸纹理按实际区域大小绘制 |

领域的形成、持续、结束与真实状态绑定。钟面指针仅表示局部弹道时间，没有扫过伤害。漂移、指针与招式动画使用正常战斗时钟，选卡和暂停时停止；紧凑模式只加快关卡进程。

## 缓存与预算

原始帧的时长、alpha、原点、可见边界、朝向和来源保留在 manifest。共享的小型战斗素材预加载；敌人专用弹道和命中随当前遭遇外观预加载。切帧使用已缓存的 GPU 纹理。

沿用 128 个技能表现事件和 40 个命中事件预算。敌方收尾最多 48 个，0.55 秒内清理；弹道尾迹只保留 4 个实际位置。高密度时先减少烟团、纹理补充和尾迹，不把召唤本体退化成几何图。

## 来源与复现

完整映射见 [素材来源表](assets/battle_art_sources.json)，逐帧数据见 `assets/manifest.json`。原始 NX/WZ 始终只读，仓库只包含选择性提取的 PNG 与来源记录。

```powershell
python tools/extract_battle_art.py <包含各NX的本地目录>
```

机械、幻影相关的新职业技能在当前 Skill.nx 中缺失。本地旧服务器 XML 没有这些技能的可用画布；较新分包 WZ 客户端存在，但本项目没有可直接复用的选择性解码器。因此上述机械本体、蝙蝠和卡片明确记录为同主题替代，不声称完成对应现代技能的逐帧还原。

定向画面入口为 `--battle-scene 0..4`，分别查看地面召唤、飞行召唤、烟幕/钟表、装备/等级压制，以及多源融合。配合 `--capture-sequence <本地目录> --capture-every 12` 可保存原生后缓冲连续帧。所有诊断应提供隔离的 `--save-dir`，截图与性能记录放在被忽略的 `artifacts/`，不放入发布包。

代表性场景检查不能替代逐一检查所有敌人、所有融合路线和所有机器配置。具体已查看场景与机器性能记录随本地交付报告保存。
